Häufig gestellte Fragen

Wie installiere ich WAEngine?

Installation ist einfach mit npm:

npm install waengine

Danach können Sie sofort loslegen mit einem 3-Zeilen Bot!

Welche Plattformen werden unterstützt?

WAEngine läuft auf allen Plattformen:

  • Windows, macOS, Linux
  • Android (Termux), iOS (iSH)
  • Docker, Cloud Platforms
  • Raspberry Pi, ARM Devices

Wie erstelle ich einen einfachen Bot?

Mit der EasyBot API in nur 3 Zeilen:

import { quickBot } from "waengine";

quickBot()
    .when("hello").reply("Hi! 👋")
    .start();

QR Code wird nicht angezeigt - was tun?

Versuchen Sie Terminal QR als Fallback:

const client = new WhatsAppClient({
    printQR: true // Terminal QR
});
